One-minute underlying candles

GET /v1/data reads completed NIFTY and BANKNIFTY candles from bars.csv. It serves source prices without indicators or generated market data.

FieldMeaning
timestampCompleted candle close time, ISO 8601 with timezone
symbolNIFTY or BANKNIFTY
open, high, low, closeOne-minute index prices
volumeSource volume, or 0 when absent

Place your real bars.csv in the project folder, or set BARS_CSV before starting the server. The file is reloaded when it changes. Until a valid file exists, the endpoint returns HTTP 503 with a clear source error.

timestamp,symbol,open,high,low,close,volume

Optional filters: symbol, from, to, limit (1–10000), and format=json|csv. Date filters require a timezone. Encode a plus sign in a URL as %2B.

/v1/data?symbol=NIFTY&limit=100

Timestamp means the end of the completed one-minute candle. Future timestamps are excluded. Results are chronological; limit selects the most recent matching rows. Trading and login UI are deferred.
